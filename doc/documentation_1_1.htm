1    Background

The Zodiac reconstruction framework is developed for reconstruction of quantitative SPECT images. It is provided as is and comes with NO WARANTY. It is solely meant as a research tool and ALL USAGE IS AT YOUR OWN RISK.

Routines have been tested using IDL 9.2 under Windows 11. The GPU routines also require a working IDL-Python bridge with CuPy installed and use of regional voxels with perturbations requires scipy and qpsolvers.

If you find this tool useful, please cite

Reconstruction: J Gustafsson, E Larsson, and K Sjögreen Gleisner (2026). Direct estimation of activity concentration in regional voxels with application to 177Lu peptide receptor radionuclide therapy, Med Phys 53: e70424, DOI: 10.1002/mp.70424

Partial volume correction: J Gustafsson, E Larsson, and K Sjögreen Gleisner. Dimensionality reduction for partial-volume correction in quantitative SPECT, Phys Med Biol (2026)

2    Image classes

2.1  gs_Image

Parental class for image data. It is primarily meant to be inherited by other classes. The class inherits from the IDL_object class.

Properties

imgData: The image data stored (n-dimensional matrix, floating point). Data input as floating-point double precision will be stored in this format. All other formats will be stored as floating point single precision.

nDimensions: The number of dimensions of the image (scalar integer).

dataDims: The image matrix size (integer array).

numberFormat: Indication of the image data format (scalar string). Possible values are ‘double’ or ‘single’.

nonNegative: Indication if negative values are allowed (scalar Boolean). If set to !true, any negative values will be set to zero.

Methods

Init

oImg = gs_Image(data, [/nonNegative])

data: n-dimensional matrix containing the image fata

nonNegative: Keyword to set the nonNegative property for the object.

Return value: Object reference 

GetRegion

oImgReg = oImg.GetRegion(regions, regionName)

regions: Object reference of type gs_RegionMap

regionName: Scalar string with the name of a region in regions.

Return value: Object reference of the same type as oImg where all pixels in region name are set to one and all other pixels set to zero.

Rescale

oImgRscl = oImg.Rescale(rescaler, regions)

rescaler: Object reference of type gs_Rescaler

regions: Object reference of type gs_RegionMap

Return value: Object reference of the same type as oImg where the rescaler has been applied

New

oImgNew = oImg.New(imgData, [/nonNegative])

imgData: n-dimensional matrix containing the image data

nonNegative: Optional keyword to set the nonnegative property. If not specified, the property will be to the same value as for oImg.

Return value: Object reference of the same type as oImg containing the image data.

Overloaded operators

+: Add images

- (binary): Subtract images

- (unary): Negate image

*: Multiply images

/: Divide images

2.2   gs_Projections

Parental class for projection data. It is primarily meant to be inherited by other classes. The class inherits from gs_Image.

Properties

mtxSiz: Projection matrix size (two-element integer array).

pixSiz: Projection pixel size in centimetres (two-element double array)

nProjections: Number of projections (scalar integer).

energyWindow: Energy window for the projections (scalar gs_EnergyWindow)

Methods

Init

oPrj = gs_Projections(imgData, energyWindow = energyWindow, pixSiz = pixSiz, [/nonNegative])

imgData: Three-dimensional matrix containing the projection data.

energyWindow: Object reference of type gs_EnergyWindow that specifies the energy window.

pixSiz: Two-dimensional array that specifies the projection pixel size.

nonNegative: Optional keyword to set the nonnegative property of the projections.

Return value: Object reference of type gs_Projections.

Expand

oPrjExp = oPrj.Expand(numberOfSlices)

numberOfSlices: Number of rows to be added to each projection. If set to a two-element integer array, it specifies the number of rows to be added at top and bottom of the projections, respectively. If set to a scalar integer, it specifies the number of rows to be added to both top and bottom.

Return value: An object reference of the same type as oPrj containing the expanded projections.

Crop

oPrjCrp = oPrj.Crop(numberOfSlices)

numberOfSlices: Number of rows to be removed from each projection. If set to a two-element integer array, it specifies the number of rows to be removed from top and bottom of the projections, respectively. If set to a scalar integer, it specifies the number of rows to be removed from both top and bottom.

Return value: An object reference of the same type as oPrj containing the cropped projections.

Overloaded operators

#: Filter projections with a gs_Filter.

2.3  gs_StandardCameraProjections

Object class for storing projections from an ordinary gamma camera that with detectors rotation around the patient. The class inherits from gs_Projections.

Properties

cor: Centre-of-rotation for each projection (numeric 2×n matrix)

prjDist: Distance from cor to collimator face for each projection in centimetre (double array).

prjTime: Projection time for each projection in seconds (double array)

prjAnge: Projection angles in degrees (Double array). Ang angle of zero corresponds to a vector pointing along the positive x-axis. The angle increases counterclockwise.

nHeads: Number of camera heads (scalar integer).

axialOffset: Axial offset in centimetres for projections (Double array)

nBeds: Number of bed positions for the acquisition (scalar integer). This will always be one for this object class.

Methods

Init

oPrj = gs_StandardCameraProjections(imgData, energyWindow = energyWindow, pixSiz = pixSiz, cor = cor, prjDist = prjDist, prjTime = prjTime, prjAngles = prjAngles, [nHeads = nHeads], [axialOffset = axialOffset], [/nonnegative])

imgData: Three-dimensional matrix containing the projection data.

energyWindow: Object reference of type gs_EnergyWindow that specifies the energy window.

pixSiz: Two-dimensional array that specifies the projection pixel size.

cor: Floating-point matrix specifying the coordinates for centre-of-rotation. The matrix should be of size 2×number of projections

prjDist: Floating point array with projection distances (distance from COR to collimator face).

prjTime: Floating point array with projection times.

prjAngles: Floating point array with projection angles

nHeads: Optional keyword to specify number of detector heads. Default is two.

axialOffset: Floating point array to specify the axial offsets.

nonnegative: Optional keyword to set the nonnegative property of the projections.

Return value: Object reference of type gs_StandardCameraProjections.

3    Image processing

3.1  gs_RegionMap

Object class for defining labelled regions. Regions cannot overlap. The object class inherits from IDL_object.

Properties

dataDims: Matrix size for the region map (three-element double array).

names: Names of the regions (string array).

regions: Region map (three-dimensional short integer array). Values of zero indicate that no region has been defined for the voxels.

Methods

Init

oReg = gs_RegionMap(regions, [names = names], [labels = labels])

regions: Three-dimensional integer array that specifies the labelled regions. Values different from zero indicate that the voxel belongs to a region.

names: Array that specifies the names of the different regions. Default is that regions are named region1, region2, etc.

labels: Integer array that connects the region names with different labels. Default is that labels are named in ascending order.

Return value: Object reference of type gs_RegionMap

Indices

ii = oReg.Indices(name | /undefined, count = count)

name: Name of the region for which indices should be returned. The argument is ignored if the undefined keyword is set.

undefined: Keyword that if set the indices for voxels that do not belong to any region will be returned.

count: Number of voxels in the region.

Return value: Indices for the region.

ToFile

oReg.ToFile, filename, [/compress], [/overwrite]

Store the object to file.

filename: Full path to the file to be written.

compress: Optional keyword to compress the file content.

overwrite: Optional keyword to allow existing files to be overwritten. Default behaviour is that an attempt to overwrite an existing file raises an error.

FromFile (static)

oReg = gs_RegionMap.FromFile(fileName)

filename: Full path to the file where the region map object is stored.

Return value: Object reference of type gs_RegionMap

Add

oReg.Add, ii, name, [/remove]

Add a region to the region map.

ii: indices for the region.

name: Name of the region.

remove: Keyword that if set causes the elements in ii to be set to undefined. The argument name will be ignored.

Mask

msk = oReg.Mask(name)

name: Name of a region in the region map.

Return value: Binary mask corresponding to the region specified by name.

HasRegion

tof = oReg.HasRegion(name)

name: Scalar string

Return value: Scalar Boolean set to !true if the region map has a region named name and !false otherwise.

Overloaded operators

eq: Test for equality of region maps.

ne: Negation of the eq operator.

3.2  gs_Filter

Object class for filtering of images. It is only meant for inheritance of other classes and has no functionality on its own. The class inherits from the IDL_object class.

Properties

nDimensions: Number of dimensions for the filter (scalar integer).

mode: Mode of implementation for the filtering (scalar string). A value of ‘fft’ means that the filter will be applied using the fast Fourier transform and the convolution theorem. A value of ‘convol’ means that the filtering will be performed by the Convol function.

3.3  gs_GaussianFilter

Object class for low-pass filtering of images with a Gaussian kernel. The object class inherits from the gs_Filter class.

Properties

FWHM: The FWHM of the Gaussian filter (double array).

Methods

Init

oFilt = gs_GaussianFilter(fwhm = fwhm, nDimensions = nDimensions, mode = mode)

fwhm: FWHM of the filter. If provided as a scalar, the filter will be isotropic. If provided as an array, it specifies the FWHM in each direction.

nDimensions: The number of dimensions for the filter. The value should be an integer between one and three.

mode: Mode of implementation for the filtering (scalar string). A value of ‘fft’ means that the filter will be applied using the fast Fourier transform and the convolution theorem. A value of ‘convol’ means that the filtering will be performed by the Convol function.

Return value: object reference of type gs_GaussianFilter

GetFilter

flt = oFilter.GetFilter(dataDims, binSize, padTo = padTo)

dataDims: The matrix size of the filter.

binSize: Tbe bin size of the filter matrix in centimetres.

padTo: The matrix size to which the filter should be zero-padded.

Return value: A matrix of the specified size that contains the filter. If the mode of the filter is set to fft, the filter will be in Fourier space, and in the spatial domain otherwise.

3.4  gs_GaussianPSF

Object class for filtering with a Gaussian PSF. The functionality is the same for as for gs_GaussianFilter but is computationally more efficient because the matrix size and bin size is specified at initialization rather than at the time of the convolution. The object class inherits from gs_GaussianFilter.

Properties

Init

oPSF = gs_GaussianPSF(fwhm = fwhm, mode = mode, dataDims = dataDims, voxelSize = voxelSize)

fwhm: FWHM if the PSF in centimetres. If provided as a scalar, the filter will be isotropic. If provided as an array, it specifies the FWHM in each direction.

mode: Mode of implementation for the convolution (scalar string). A value of ‘fft’ means that the PSF will be applied using the fast Fourier transform and the convolution theorem. A value of ‘convol’ means that the convolution will be performed by the Convol function.

dataDims: Integer array that specifies the size of the PSF matrix. The number of elements implicitly defines the number of dimensions for the corresponding Gaussian filter.

voxelSize: Floating-point array that specifies the voxel size in centimetres. The number of elements must be the same as dataDims.

Return value: Object reference of type gs_GaussianPSF

GetFilter

flt = oFilter.GetFilter(dataDims, binSize, padTo = padTo)

dataDims: The matrix size of the filter. An error will be raised if the matrix size does not agree with the one specified at initialization.

binSize: Tbe bin size of the filter matrix in centimetres. An error will be raised if the bin size does not agree with the voxel size specified at initialization.

padTo: The matrix size to which the filter should be zero-padded. An error will be raised unless the padded value is not twice the matrix size

Return value: A matrix of the specified size that contains the PSF. If the mode of the PSF is set to fft, the PSF will be in Fourier space, and in the spatial domain otherwise.

9    File formats

9.1  .src

File format for storing sources.

Size of source matrix: 3 longword integers

Nonnegativity of the source: 1 Boolean. A value of !true indicates that negative values are forbidden.

Number format: 6 characters. A value of single means that data are floating-point single precision, while a value of double means that data are floating-point double precision.

Voxel size of the source matrix: 3 double floating points. Values are given in centimetres

Compression of source matrix: 1 Boolean. A value of !true indicates that the source matrix has been compressed as gzip.

Number of lines for the radionuclide: Longword integer stating the number of lines for the radionuclide specification.

Radionuclide: A series of strings appropriate for input as an array to the gs_radionuclide.Restore static method. Each line is preceded by a longword integer specifying the number of bytes to be read for the string.

Image data: The storage of image data depends on whether the compression flag is set or not. If set to !false, data is stored as raw binary data with length according to the size of the source matrix and the data type specified by the number format. If set to !true, a doubleword integer states the number of bytes of data to be read. The data is compressed as gzip (including header).

9.2  .reg

File format for storing region maps.

Number of dimensions: Longword integer specifying the number of dimensions for the region map.

Size of the region map matrix: Longword integer array with the number of elements specified by the number of dimensions.

Number of bytes used for storing region names: Longword integer.

Region names: Sting with individual region names separated by commas.

Region labels: Array of short-word integers specifying the region labels corresponding to the region names.

Data compression flag: Boolean. If !true the region map matrix is compressed as gzip.

Image data: The storage of region map data depends on whether the compression flag is set or not. If set to !false, data is stored as raw short-word integer binary data with length according to the size of the region map matrix. If set to !true, a doubleword integer states the number of bytes of data to be read. The data is compressed as gzip (including header).

9.3  .rnc

File format for storing radionuclide data as an ascii file.

First line: Half-life in hours

Following lines: Energy and yield separated by a comma

9.4  .nsrc

File format for storing natural sources.

Version: Two-character string that specifies the version number. Current version is v1.

Size of source matrix: 3 longword integers

Nonnegativity of the source: 1 Boolean. A value of !true indicates that negative values are forbidden.

Number format: 6 characters. A value of single means that data are floating-point single precision, while a value of double means that data are floating-point double precision.

Voxel size of the source matrix: 3 double floating points. Values are given in centimetres.

Emulated matrix size: 3 longword integers

No-force flag: Boolean

Compression flag: Boolean. If set to !true the source matrix is compressed using gzip.

Number of lines for the radionuclide: Longword integer stating the number of lines for the radionuclide specification.

Region flag: Boolean flag that indicates if there is a region map associated with the source.

Number of lines for the radionuclide: Longword integer stating the number of lines for the radionuclide specification.

Radionuclide: A series of strings appropriate for input as an array to the gs_radionuclide.Restore static method. Each line is preceded by a longword integer specifying the number of bytes to be read for the string.

Image data: The storage of image data depends whether the compression flag is set or not. If set to !false, data is stored as raw binary data with length according to the size of the source matrix and the data type specified by the number format. If set to !true, a doubleword integer states the number of bytes of data to be read. The data is compressed as gzip (including header).

Region data: If the region flag is set to !true, the remaining of the file contains a region map, specified according to the reg-format.

9.5  .bs

File format for storing region-perturbed bases. In practice, a stand-alone file is seldom created but rather embedded in basis-source files (.bsrc).

Variant for gs_FourierBasis

Version: Five-character string specifying the file-format version . Current value is fbv01

Voxel size: Three-element floating-point array (double position) specifying the voxel size in centimetres.

Number of regions: Number of regions specified as long-word integer.

Number of orders per region: Triplet of values per region that specifies the region name and number of perturbation orders. The first is a word integer that specifies the number of characters in the region name, followed by the region name as a string and the number perturbation orders as a long-word integer.

Region map: Region map saved according to the format for .reg files.

9.6  .bsrc

File format for storing basis sources.

Version: Five-character string that specifies file-format version. Current version is bsv01.

Emulated matrix size: Three-element long-word integer array that specifies the emulated matrix size.

Non-negativity flag: Boolean that specifies if all values are forced to be non-negative or not.

Number format: Six-character array that specifies the number format of the image. Allowed values are single and double, specifying single- and double precision, respectively.

Compress: Boolean that specifies if data is compressed or not. 

Basis name length: Word integer that specifies the number of characters of the basis object class.

Basis class: Name of the basis object class as a string with the number of characters specified by the basis-name length.

Basis: Image basis according to the format specified by .bs

Number of radionuclides: Number of radionuclides in the source.

Radionuclides: Source radionuclides according to the format specified by .rnc.

Number of regions: Number of regions in the basis specified as a long-word integer.

Region coordinates: Coordinates in the region-perturbed basis. Each field consists of a word integer that specifies the name of the region followed by a string with that name. The following three long-word integers specify the order number for the basis function in x-, y- and z-directions followed by a floating-point double precision value that specifies the coordinate.

Number of cuboid voxels: Long-word integer number of cuboid voxels not belonging to any regional voxel.

Voxel values for undefined region: Voxel values for cuboid voxels not belonging to any regional voxel. If the compress flag is set to true, the array is stored in gzip format (including heder) preceded by the number of bytes occupied in memory specified as a long-word integer. If the compress flag is set to false, the array is stored directly without any compression.

9.7  .prim

File format for specifying the detector’s relative sensitivity to photon energies. Each line starts with an energy-window range, with lower and upper limits separated by a dash (-). The window is followed by a colon and after the colon follows a semicolon separated list with pairs of energies and relative sensitivities separated by commas.

9.8  .geo

File format for specifying geometric detector models. The first part of the file is the same as for .prim. The second part is marked by a line with a single hash (#). The second part consists of a series of tags and values (one per line) separated by colons.

hole width: <flat-to-flat distance in centimetres>

collimator depth: <collimator depth in centimetres>

hole shape: hex

gap: <distance between the back of the collimator and the image plane in centimetres>

10     Examples

10.1                Reconstruction of 99mTc images with DEW

Simulated projections for 99mTc are provided in the examples-directory of the Zodiac installation. The simulated acquisition is for 60 projections over 360○ starting at 90○ with counterclockwise rotation in 128×128 matrix with 0.442×0.442 cm2 pixels. The main energy window is 129.5 keV to 150.5 keV and the scatter window is 121.1 keV to 129.5 keV.

The file jg_polluxexampletc.pro in the examples-directory performs a SPECT reconstruction with compensation for attenuation, scatter using the DEW method and geometric detector resolution. The reconstructed image can be read from file as

oSrc = gs_Source.FromFile('<path-to-examples-directory>\test_tc99m.src')

TvScl, oSrc.imgData[*, *, 64]

An alternative implementation of the same reconstruction can be found in jg_polluxexampletcgpu.pro, where the matrix rotation is performed on the GPU rather than CPU. Note that the use of GPU requires a working IDL-Python bridge with CuPy. Depending on hardware, the GPU implementation may result in a substantial performance enhancement compared with CPU.

10.2                Reconstruction with natural voxels

The file jg_polluxexampletcnatural.pro in the examples-directory performs SPECT reconstruction of the same source as in example 9.1 but using a mix of natural and cuboid voxels. The reconstructed image can be read from file as

oSrc = gs_NaturalSource.FromFile('<path-to-examples-directory>\test_tc99m.nsrc')

TvScl, oSrc.imgData[*, *, 64]

10.3                Reconstruction of 177Lu using two energy windows

The file jg_polluxexamplelu.pro in the examples-directory performs tomographic reconstruction of simulated 177Lu projections using two separate energy windows in combination. The reconstruction includes compensation for attenuation, scatter using the ESSE method, and geometric detector resolution. The reconstructed image can be read from file as

oSrc = gs_Source.FromFile('<path-to-examples-directory>\test_lu177.src')

TvScl, oSrc.imgData[*, *, 64]

10.4                Post-reconstruction PVC

The file jg_postreconstructionpvc.pro in the examples-directory performs post-reconstruction PVC of a 177Lu-SPECT image of eight spheres in a warm background. Partial-volume correction is performed using Lucy-Richardson’s algorithm cuboid voxels (i.e., ordinary Lucy-Richardson deconvolution) and Lucy-Richardson’s algorithm with regional voxels with cosine perturbations (i.e., region-perturbed Lucy-Richardson deconvolution). Note that the latter technique requires a working IDL-Python bridge with scipy and qpsolvers installed. Results are saved to file and can be inspected using

oSrc = gs_Source.FromFile('<path-to-examples-directory>\test_lu177_208_lrd.src')

TvScl, oSrc.imgData[*, *, 64]

for ordinary Lucy-Richardson deconvolution and  

oSrc = gs_Source.FromFile('<path-to-examples-directory>\test_lu177_208_lrd.bsrc')

TvScl, oSrc.imgData[*, *, 64]

for region-perturbed Lucy-Richardson deconvolution.
